# Documentation

This directory contains internal documentation for maintaining and understanding the `toddbradley.com` website.

## Contents

- **[architecture.md](architecture.md)**: The "memory jogger". Explains how all the pieces (Jekyll, Cloudflare, Comentario, Railway, Buttondown, GitHub Actions) fit together, including setup instructions.
- **[conversion-history.md](conversion-history.md)**: Historical notes on how the original WordPress export was converted to Jekyll.

This directory is excluded from the Jekyll build (see `exclude` in `_config.yml`), so it is not published on the live site.
